# 🇬🇧 English Documentation

## Overview

When power is restored following an electrical blackout, most modern Smart TVs (Google TV, Android TV, Samsung Tizen, LG webOS, Sony Bravia) enter a passive **Standby mode** and remain turned off.

**ESP32 HDMI-CEC TV Autostart** is a self-contained device that plugs directly into any HDMI port on your TV:
1. **Primary Target Hardware**: **ESP32 WROOM (DevKit v1)** (Default). *Secondary/Optional: ESP32-C3 Super Mini.*
2. Powered directly via the HDMI connector's **Pin 18 (+5V)** and **Pin 17 (GND)**.
3. Reads current time from a battery-backed **DS3231 RTC Module** and computes the exact **outage duration**.
4. Waits for a configurable startup delay (`WAIT_SECONDS = 15s`) to allow the TV's power supply and standby controller to boot up.
5. Transmits standard **HDMI-CEC** commands:
   - `<Image View On>` (`0x04`): Wakes the TV screen from Standby.
   - `<Active Source>` (`0x82`): Selects and displays the active HDMI port.
6. Saves the new boot timestamp to non-volatile storage (AT24C32 EEPROM / NVS) for future outage diagnostics.

## ⚡ How to Flash the Firmware (Step-by-Step)

### 🌟 Method 1: Browser-Based Web Flashing (Recommended — Zero Coding!)

This is the fastest, easiest method. You do not need to install Python, drivers, or terminal tools.

1. Connect your ESP32 board to your computer via a **USB Data Cable**.
2. Open Google Chrome, Microsoft Edge, or Brave.
3. Visit an online ESP Web Flasher tool such as:
   - [ESP Web Tools](https://esphome.github.io/esp-web-tools/) or
   - [Adafruit WebSerial ESPTool](https://adafruit.github.io/Adafruit_WebSerial_ESPTool/)
4. Click **Connect** and select your ESP32 COM / Serial port from the pop-up list.
5. Choose the downloaded `esp32-wroom-complete-flash-offset-0x0.bin` file, set flash offset to `0x0`, and click **Program / Flash**.
6. Once complete, unplug the ESP32 and plug it into your TV's HDMI port!

---

### 💻 Method 2: Flashing via `esptool.py` (Command Line)

If you prefer using the command line:

#### Step 1: Install Python and `esptool`
Ensure [Python](https://www.python.org/) is installed, then open your terminal (Command Prompt / PowerShell / Terminal) and run:
```bash
pip install esptool
```

#### Step 2: Identify your ESP32 COM Port
- **Windows**: Open **Device Manager** → Expand **Ports (COM & LPT)** → Look for `Silicon Labs CP210x` or `USB-SERIAL CH340` (e.g. `COM3` or `COM5`).
- **macOS**: In Terminal, run `ls /dev/cu.usbserial*` or `ls /dev/cu.wchusbserial*`.
- **Linux**: In Terminal, run `ls /dev/ttyUSB*` or `ls /dev/ttyACM*`.

#### Step 3: Flash the Firmware
Replace `COM3` with your actual port name:

- **Option A (Recommended: Flash Merged All-in-One Binary at `0x0`)**:
  ```bash
  esptool.py --chip esp32 --port COM3 --baud 460800 write_flash 0x0 esp32-wroom-complete-flash-offset-0x0.bin
  ```

- **Option B (Flash Application Firmware only at `0x10000`)**:
  ```bash
  esptool.py --chip esp32 --port COM3 --baud 460800 write_flash 0x10000 esp32-wroom-firmware.bin
  ```

> [!TIP]
> **Flashing Troubleshooting:**
> - If connection fails or times out, hold down the **BOOT** button on your ESP32 board while executing the command.
> - If upload fails mid-way, reduce the baud rate to 115200:
>   `esptool.py --chip esp32 --port COM3 --baud 115200 write_flash 0x0 esp32-wroom-complete-flash-offset-0x0.bin`
> - If the COM port is not detected at all, install the [CP210x Driver](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers) or [CH340 Driver](https://sparks.gogo.co.nz/ch340.html).

### 🛠️ Method 3: Compile Locally with PlatformIO

1. Clone this repository:
   ```bash
   git clone https://github.com/OWNER/REPO.git
   cd esp32-hdmi-cec-tv-autostart
   ```
2. Build and upload directly:
   - For **ESP32 WROOM (DevKit v1)** *(Default)*:
     ```bash
     pio run -e esp32dev -t upload
     ```
   - For **ESP32-C3 Super Mini**:
     ```bash
     pio run -e esp32c3 -t upload
     ```
3. To generate the local `.bin` file without uploading:
   ```bash
   pio run -e esp32dev
   ```
   The compiled file will be located at: `.pio/build/esp32dev/firmware.bin`.

## Troubleshooting Guide

### 1. TV Not Responding to Wake-Up Commands
- **Enable HDMI-CEC in TV Settings**: Ensure HDMI-CEC is enabled in your TV menu:
  - **Google TV / Android TV**: *Settings → Display & Sounds → HDMI-CEC → Enable CEC Control & Device Auto Power On*.
  - **LG (webOS)**: *Settings → All Settings → General → Devices → HDMI Settings → SIMPLINK (HDMI-CEC)*.
  - **Samsung (Tizen)**: *Settings → General → External Device Manager → Anynet+ (HDMI-CEC)*.
  - **Sony (Bravia)**: *Settings → Watching TV → External inputs → BRAVIA Sync settings*.
- **Adjust Startup Delay (`WAIT_SECONDS`)**: If the TV power supply takes longer to initialize its CEC receiver, increase `WAIT_SECONDS` in `include/config.h` (e.g., from `15` to `20` or `25`).
- **Physical Address Match**: If your device is plugged into HDMI 2, adjust `HDMI_PHYSICAL_ADDRESS` in `include/config.h` to `0x2000` (Port 1 = `0x1000`, Port 2 = `0x2000`, Port 3 = `0x3000`).

### 2. RTC Not Retaining Time Across Outages
- **CR2032 Coin Cell**: Verify that the CR2032 battery measures at least 2.9V - 3.2V with a multimeter.
- **ZS-042 Module Modification**: Some generic blue "ZS-042" DS3231 modules include an aggressive trickle-charging circuit designed for rechargeable LIR2032 cells. If using a standard non-rechargeable CR2032, desolder the 200Ω resistor or charging diode (marked `D1` / `R5`) to prevent overcharging.

### 3. Power Stability & HDMI Pin 18 Current Limitation
- **Specification Limit**: HDMI specifications require TV ports to supply at least **55mA at +5V** on Pin 18.
- **Brownout Prevention**:
  - Solder a **100µF - 220µF low-ESR electrolytic capacitor** across the `5V` and `GND` pins to buffer current during transmission peaks.
  - If a specific TV model cuts 5V power entirely in Standby mode, you can optionally connect the ESP32's 5V input to a nearby TV USB port (which provides 500mA) while keeping HDMI Pin 13 (CEC) and Pin 17 (GND) connected to the HDMI port.

# 🇸🇦 النسخة العربية

## نظرة عامة على المشروع

عند انقطاع التيار الكهربائي وعودته، تدخل معظم شاشات التلفزيون الذكية الحديثة (Google TV، Android TV، سامسونج، LG، سوني) تلقائياً في **وضع الاستعداد (Standby)** وتبقى مطفأة ولا تعمل إلا بالضغط يدوياً على زر التشغيل في جهاز التحكم (الريموت).

مشروع **ESP32 HDMI-CEC TV Autostart** هو جهاز صغير ومستقل يتم توصيله مباشرة بمنفذ HDMI في الشاشة:
1. **اللوحة المستهدفة الأساسية**: **ESP32 WROOM (DevKit v1)** (الافتراضية). *والخيار الثانوي: ESP32-C3 Super Mini.*
2. يستمد طاقته مباشرة من منفذ الـ HDMI عبر **السن 18 (جهد 5 فولت)** و**السن 17 (الأرضي GND)**.
3. يقرأ الوقت الفعلي من موديول التوقيت **DS3231 RTC** المزود ببطارية مدمجة، ويحسب بدقة **مدة انقطاع الكهرباء**.
4. ينتظر مهلة زمنية قابلة للتعديل (`WAIT_SECONDS = 15 ثانية`) للسماح للشاشة بالإقلاع والجاهزية.
5. يرسل أوامر **HDMI-CEC** القياسية:
   - أمر تشغيل الشاشة (`<Image View On>` - Opcode `0x04`).
   - أمر تفعيل منفذ الدخل (`<Active Source>` - Opcode `0x82`).
6. يحفظ وقت الإقلاع الحالي في الذاكرة غير المتطايرة (AT24C32 EEPROM / NVS) لحساب فترات الانقطاع القادمة بدقة.

## دليل استكشاف الأخطاء وإصلاحها (Troubleshooting)

### 1. الشاشة لا تستجيب لأمر التشغيل
- **تفعيل خاصية HDMI-CEC في إعدادات الشاشة**:
  - **Google TV / Android TV**: *الإعدادات ← الشاشة والصوت ← HDMI-CEC ← تفعيل التحكم وتفعيل التشغيل التلقائي*.
  - **LG (webOS)**: *الإعدادات ← عام ← الأجهزة ← إعدادات HDMI ← SIMPLINK (HDMI-CEC)*.
  - **Samsung (Tizen)**: *الإعدادات ← عام ← إدارة الأجهزة الخارجية ← Anynet+ (HDMI-CEC)*.
  - **Sony (Bravia)**: *الإعدادات ← مدخلات خارجية ← إعدادات BRAVIA Sync*.
- **زيادة مهلة الانتظار (`WAIT_SECONDS`)**: جرب زيادة `WAIT_SECONDS` في ملف `include/config.h` من 15 إلى 20 أو 25 ثانية.
- **تطابق العنوان الفيزيائي لمنفذ HDMI**: إذا قمت بتوصيل الجهاز في منفذ HDMI 2، عدل `HDMI_PHYSICAL_ADDRESS` في `config.h` إلى `0x2000`.

### 2. موديول الساعة DS3231 يفقد التوقيت
- **فحص بطارية CR2032**: تأكد من أن قياس جهد البطارية لا يقل عن 2.9 إلى 3.2 فولت.
- **تعديل دائرة الشحن في موديولات ZS-042**: يُنصح بإزالة المقاومة 200Ω أو الدايود (المحدد بـ `D1` أو `R5`) لتعطيل دائرة الشحن عند استخدام بطارية CR2032 عادية غير قابلة للشحن.

### 3. ثبات الطاقة وحدود التيار لمنفذ السن 18 في HDMI
- صِل **مكثف 100µF إلى 220µF** بين خط الـ 5V والـ GND لامتصاص ذروات سحب التيار أثناء البث.
- في حال كانت الشاشة تقطع الطاقة تماماً عن منافذ HDMI في وضع الاستعداد، يمكن تغذية الـ ESP32 من منفذ USB قريب في الشاشة (5V/GND) مع إبقاء خط الـ CEC (السن 13) والأرضي (السن 17) متصلين بمنفذ الـ HDMI.
